Dragon Loot x Advanced Netherite - Minecraft 1.20.1 (Fabric)

Upgrade Advanced Netherite diamond-netherite equipment into DragonLoot gear
with a Dragon Scale. The Netherite Upgrade Smithing Template is also required.

Requires the original DragonLoot mod by Pois1x and Advanced Netherite for
Fabric, plus their required dependencies. Install versions matching Minecraft
1.20.1.

DragonLoot: https://modrinth.com/mod/dragonloot
Advanced Netherite: https://modrinth.com/mod/advanced-netherite

Installation: place this ZIP in your world's datapacks folder, keep it zipped,
then reopen the world or run /reload. On a dedicated server, install it in the
server world's datapacks folder. Check /datapack list enabled after loading.

The nine recipes cover the axe, boots, chestplate, helmet, hoe, leggings,
pickaxe, shovel and sword. Equipment stats and drop bonuses are configured by
the mods; this pack changes smithing recipes only.
