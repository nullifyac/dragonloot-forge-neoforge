# Dragon Loot x Advanced Netherite Compat

These packs replace nine DragonLoot smithing recipes so tools and armor upgrade
from Advanced Netherite's diamond-netherite tier using a Dragon Scale. Minecraft
1.20 and later also require a Netherite Upgrade Smithing Template.

Choose the pack matching your Minecraft version and loader. Both mods and their
required dependencies must be installed.

The Fabric packs are currently available as source; release ZIP downloads will
follow. To build a pack from source, zip the contents of its `DLxAN_*` folder so
`pack.mcmeta` is at the root of the ZIP.

| Loader | Minecraft versions | DragonLoot mod |
| --- | --- | --- |
| Forge | 1.16.5, 1.18.2, 1.19.2, 1.20.1 | [Enderdragon Loot](https://www.curseforge.com/minecraft/mc-mods/enderdragon-loot) |
| NeoForge | 1.21.1 | [Enderdragon Loot](https://www.curseforge.com/minecraft/mc-mods/enderdragon-loot) |
| Fabric | 1.19.2, 1.20.1, 1.21, 1.21.1 | [DragonLoot by Pois1x](https://modrinth.com/mod/dragonloot) |

Download matching [Advanced Netherite](https://modrinth.com/mod/advanced-netherite)
builds for your loader.

Place the pack ZIP in your world's `datapacks` folder, keep it zipped, then reopen
the world or run `/reload`. On a dedicated server, use the server world's
`datapacks` folder. Check `/datapack list enabled` after loading.

The recipes cover the axe, boots, chestplate, helmet, hoe, leggings, pickaxe,
shovel and sword. Equipment stats and drop bonuses remain controlled by the mods;
these packs change smithing recipes only.
