Dragon Loot x Advanced Netherite - Minecraft 1.20.1

This datapack replaces nine Dragon Loot smithing recipes so Dragon tools and
armor upgrade from Advanced Netherite diamond-netherite equipment, using a
Dragon Scale. The Netherite Upgrade Smithing Template is also required on this version.

Requires Dragon Loot and Advanced Netherite for Minecraft 1.20.1. Both mods
must be installed with versions matching your Minecraft version and loader.

Installation: place this ZIP in your world's datapacks folder, keep it zipped,
then reopen the world or run /reload. On a dedicated server, install it in the
server world's datapacks folder. Check /datapack list enabled after loading.

The nine recipes cover the axe, boots, chestplate, helmet, hoe, leggings,
pickaxe, shovel and sword. Equipment stats and drop bonuses are configured by
the mods; this pack only changes these crafting recipes.
