# DragonLoot for Minecraft 1.20.1 (Forge)
DragonLoot adds Ender Dragon loot and dragon gear to Minecraft.

### Installation
Install Forge for Minecraft 1.20.1 and place the built mod JAR in your instance's `mods/` directory.

See the [repository README](../../README.md) for build commands and configuration.
